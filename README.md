# 🎮 2048 Puzzle Game

A classic 2048 puzzle game built using Python and Kivy.

## ✨ Features

- 4×4 Puzzle Board
- Smooth Tile Merge Animations
- Score and Best Score
- Keyboard Arrow Controls
- Mobile Swipe Controls
- Responsive Design
- Unlimited Tile Merging
- Game Over Detection
- New Game Option

## 🛠️ Technologies Used

- Python
- Kivy
